Budget modes & funding goals

Pro-rata requires zero fixed amounts. Cycles use the first destination execution time; 30 days is not a calendar month. Changing the cycle schedule resets current progress. Reordering or editing amounts preserves a saved destination's goal; a new payee starts a new identity. Zero target disables the cap.

          How income gets routed

          Fixed allocations are paid first. Percentage allocations use the gross payment amount. Reactive requests one callback for the saved plan.

          Set the order

          Add up to 8 destinations. Give each one a fixed amount, a percentage, or both. Order is priority.

          Limit the allowance

          Grant a specific token allowance. Reduce or revoke it at any time.

          Check a receipt

          Use the source transfer hash to see the callback, allocations and any amount still to recover.

          Set spending limits

          Your wallet holds unpaid funds. A configured allowance lets the contract send allocations when the rules are met.

          • ✓ Limit payouts per income and per UTC day.
          • ✓ Keep a minimum token balance in the wallet.
