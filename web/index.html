Budget modes & funding goals

Pro-rata requires zero fixed amounts. Cycles use the first destination execution time; 30 days is not a calendar month. Changing the cycle schedule resets current progress. Reordering or editing amounts preserves a saved destination's goal; a new payee starts a new identity. Zero target disables the cap.

          The waterfall

          Rent first. Then everything else.

          Fixed bills protect what matters. Percentages reserve tax, savings, and investing. The rest stays in your wallet. Reactive enforces the order on-chain.

          Build the waterfall

          Add up to 8 destinations. Give each one a fixed amount, a percentage, or both. Order is priority.

          02

          Approve once

          The contract only moves tokens you have explicitly approved. Revoke the allowance and the automation stops.

          Forget it

          One incoming payment triggers one callback. No keeper, no spreadsheets, no monthly transfers.

          Built to be boring

          Safety is the feature.

          The waterfall is deliberately bounded: fixed amounts first, percentages capped at 100%, and one versioned rule per token. A single failed bucket does not block the rest.

          • ✓ Non-custodial — the contract never holds your principal
          • ✓ Up to 8 buckets, fixed + percentage, priority order
          • ✓ 100% total percentage cap; each payout capped by the paycheck
          • ✓ Versioned rules; stale callbacks cannot apply a new rule
          • ✓ Two callback checks, replay protection, per-bucket failure isolation
