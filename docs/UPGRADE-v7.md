# PaydaySplit v7：双模式、稳定资金桶与发薪周期

日期：2026-11-18。这是需重新部署的开发演示版本；没有真实测试网全链路或外部审计。

## 本轮功能

- Waterfall：固定额 + 毛收入比例，按桶顺序支出；保持既有语义。
- ProRata：只允许活动桶的固定额为零；从共同预算 `B = min(收入, 余额, 授权, 单次上限, 当日剩余额度, 扣除保留余额后的可用额)` 计算 `floor(B × bps / 10000)`。零上限表示未设置该上限。所有桶权重总和不超过 100%。
- 同一桶目标封顶、失败、停用后的份额及舍入尾差留在钱包，不放大其他桶权重。例如收入 1000、单次限额 600、50/30/20 得到 300/180/120，保留 400。
- 稳定桶 ID：`setBucketsWithIds` 传零新建、传已有 ID 保留身份；排序、权重、模式变化保留已付进度。已有 ID 不能更换收款方，不能重复使用；最多 8 桶。移除再加入同一 ID 可继续该身份的进度。
- 旧 `setBuckets` 兼容接口仅在同位置同收款方时保留 ID；排序应使用带 ID 接口。`BucketsSet` 数组 ABI 保持兼容，新增 `BucketIdentities` 事件。
- 自动周期：UTC 锚点 + 1–365 天固定秒数；前端提供 7/14/30 天。周期额度按需重置，不需定时发送重置交易；无自动滚存，也不称为自然月。
- 新增 50/30/20 预算和 80/20 应急储蓄模板、模式/周期编辑器、备份 schema v2（继续兼容 v1）。导入分步保存，不替用户授权或恢复已付款历史。

## 周期与目标的精确定义

`period = floor((block.timestamp - anchor) / duration)`，基于**目标链执行时间**。Omni `LogRecord` 没有来源区块时间，本轮不伪造来源时间。延迟到下一周期的首次执行使用新周期；未来重试模块必须明确冻结原周期规则。

1. 锚点之前的收入被策略阻挡、全部保留，该来源键仍被消费，不会到锚点自动补付。
2. 修改锚点/时长或切回手动模式会新开计账代次、重置有效进度。完全相同的配置保存不重置。变更立即作用于已排队回调。
3. 自动模式禁止手动“Start new cycle”；手动模式保留原功能。目标金额修改保留已付进度；目标为零关闭目标上限，关闭期间付款不累计目标。
4. 自动周期只重置目标 paid；当天日限额独立累计，切换规则/周期不能清空当天已花费。
5. `bucketGoals(user,token,version,index)` 将旧版本位置映射到稳定 ID 后返回该 ID **当前**进度，不是历史快照。历史付款应从事件索引，不能把旧版本查询作为历史余额。

## 回调与安全

双重认证、防重放、版本校验和失败隔离保持有效。不可读余额或授权按零容量处理；每次读取最多 30,000 gas，每桶转账自调用最多 120,000 gas。请求回调 gas 为 1,500,000，兼容更多失败路径；该上限可能跳过开销很高的非标准代币，真实 Proxy 的费用及额外开销待测试网验证。

支持标准 ERC20。无返回值但成功的转账可兼容；转账税、rebase、ERC777 hooks 和恶意余额/授权返回不属于支持承诺；本版本不通过余额差自动适配这些代币。生产应建立代币白名单和独立适配器。

跳过的桶没有自动重试。`runSplit` 是一次独立手动付款；`recoverSplit` 仅适合未消费的来源键，不能补付已消费事件中的失败桶。原生 ETH 路由、桥结算、真实流式工资、生息和冷静期未实现。

## 复现与迁移

见 [TESTING.md](TESTING.md)。本地默认流程运行后，在 web 执行 `npm run local:budget`，验证目标 350 下连续付款 300 → 50 → 0，推进 7 天后再付 300；每笔都对比预演与余额增量，并验证重复投递无付款。证据：[31337.budget-v7.evidence.json](../deployments/31337.budget-v7.evidence.json)。

现有合约不可原地升级。暂停旧规则 → 处理旧任务 → 导出草稿 → 部署 v7 核心/Reactive 并绑定 → 用户检查新规则/模式/周期/目标 → 撤销旧授权 → 给新地址有限授权 → 小额验收。不得同时启用两套监听来分配同一收入；不能未经确认导入旧 paid 进度。

部署示例按 6 位 demo-USDC 配置，默认授权 1000 demo-USDC；真实代币需核对精度和基准单位。默认全局管理员暂停权、回调预算和订阅费用仍需运维。本轮没有新增代理升级入口。
