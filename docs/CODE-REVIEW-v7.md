# PaydaySplit v7 代码勘误与优化记录

日期：2026-11-18。范围：src、测试、前端、部署/验证/打包脚本、CI 和当前交付文档。本次为开发自查及回归验证，不是独立安全审计，也不保证没有未发现问题。

| 发现 | 修正与证据 |
|---|---|
| 规则数组位置改变会更换目标命名空间，排序可能意外重新支付已满目标 | 稳定身份、收款方约束、版本位置映射；排序/新收款方/无效 ID 回归 |
| 在受限预算下比例若逐步使用剩余额度，结果会受顺序影响 | 先冻结共同预算 B，再算每桶份额；比例模糊测试对比预演和实付 |
| 极端收入预演中 fixed + percentage 可溢出 | 安全 mulDiv，结果在收入上限饱和；最大 uint256 预演测试 |
| 外部代币调用可耗尽 gas，后续桶无法执行 | 有界读取和转账自调用；不可读余额/授权按零容量；7 个耗尽 gas 的桶后最后一个仍支付的 MockProxy 测试 |
| 部署环境变量先转窄整数，超大值可能被截断 | 先验证 uint96 和 bps 总和，再转换；默认有限授权，forceApprove 兼容零后再授权代币 |
| PowerShell dotenv 将 .env.example 的行尾注释当数值读取 | 共用不执行代码的解析器，支持简单单/双引号；7 项解析校验纳入 CI |
| verify.ps1 查询函数未转发 user/token 等参数 | 显式接收剩余参数、检查退出状态，纠正日志输出描述 |
| 本地部署命令失败可能继续使用缓存产物 | 构建、系统合约安装、规则配置和回调验证失败立即停止 |
| JS Number 可能损失大额模拟收入精度 | 样例金额以字符串 parseUnits，分配计算使用整数；显示近似格式与实际计算分离 |
| 导入目标草稿在链上返回新 ID 时丢失 | 按规范化规则承接草稿；模拟真实返回 ID 的前端回归，绝不导入 paid |
| 钱包读取结果可能在断连后写回旧状态 | 规则、余额、目标、策略读取增加当前账户校验；链/账户切换重新载入页面 |
| 演示交易 ID 在列表满 10 条后重复 | 独立递增演示 nonce |
| 周期锚点界面只显示到分钟，原样保存可能丢掉秒并开启新周期 | 保留秒精度和自定义时长；真实模式原样保存参数回归 |
| 文档中的测试数量、交易哈希与当前证据漂移 | 更新当前入口与提交草稿，历史版本升级说明保留；当前本地哈希统一引用机器证据 |

## 依赖公告核对

官方 npm 源全依赖扫描：[npm-audit-v7.json](../deployments/npm-audit-v7.json)，报告 4 个 high 条目，根因是同一个 picomatch 正则拒绝服务公告传播至 fdir/tinyglobby/Vite，不能当作 4 个独立根因。查询时最新 picomatch 为 4.0.7，公告注明尚无修复版本；兼容更新没有消除该公告，因此没有声称已修复，也不伪造清零结果。

公告：[GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)。当前 glob 来源是仓库受信配置，开发服务器仅监听 127.0.0.1；前端不接受用户提供的构建 glob。发布采用静态构建文件，不能把 Vite 开发服务直接作为公共生产服务。此为暴露面约束，不能代替上游补丁。

运行时依赖扫描：[npm-audit-production-v7.json](../deployments/npm-audit-production-v7.json)，0 条已知公告。这个结果不覆盖开发依赖，更不代表合约已审计。上游发布补丁后应更新锁文件、全量扫描并复跑测试。

## 尚未解决的产品/安全工作

- 已消费事件中的失败桶没有重试队列；需按桶保存幂等任务，不能整笔重放。
- 真实网络费用、回调 gas 与长时间运行尚未验收；本地 Mock 不模拟全部系统行为。
- 动态周期配置可由用户重置自己的目标进度，这是明确授权动作；管理员权限拆分、协议资金限额尚未实现。
- 自动周期按执行时间归属；来源周期归属需可靠时间证明和单独状态机。
- 非标准代币、桥、工资流、生息与 ETH 本金适配器需独立审查；浏览器视觉验收和外部审计待完成。
